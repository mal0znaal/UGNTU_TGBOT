# Умный Telegram-бот для анализа одежды

Привет! Это проект нейросетевого Telegram-бота, который умеет распознавать одежду на фотографиях с помощью искусственного интеллекта. 

**Зачем это нужно?** 
Проект помогает автоматизировать работу интернет-магазинов, стилистов или маркетплейсов. Бот сам находит главную вещь на фото, обрезает лишний фон, определяет её цвет (и присылает цветной квадратик), категорию, стиль и подходящий сезон.

---

## Как запустить проект

Для запуска вам не нужно уметь программировать! Понадобится только установленная программа **Docker Desktop** (она сама настроит все сложные технические детали под капотом).

**Шаг 1. Скачайте нейросети**
Скачайте папку с готовыми моделями (весами) с Google Диска, которую вам выдал преподаватель. Поместите её в папку проекта так, чтобы получился путь `ml_service/models`.

**Шаг 2. Настройте бота**
В папке `tg_bot` найдите (или создайте) текстовый файл с названием `.env`. Напишите в нем одну строчку с токеном вашего бота (его выдает BotFather в самом Telegram):
`BOT_TOKEN=ваш_токен_здесь`

**Шаг 3. Запуск**
Откройте терминал (командную строку) прямо в папке с этим проектом и введите всего одну команду:
`docker compose up --build`

Вот и всё! Как только в черном окне перестанут бежать строчки, бот готов к работе. Открывайте Telegram и отправляйте ему фотографии.

## Как посмотреть, как думает ИИ?
Бот не просто отвечает текстом, но и сохраняет визуальные отчеты своей работы. Загляните в папку `ml_service/inference_results`. Там вы найдете картинки "До/После": слева будет оригинальное фото, справа — вещь с удаленным фоном, а сверху плашка с выводами нейросети.
