# Telegram-бот для визуального анализа одежды

Система автоматического распознавания и классификации одежды на фотографиях с использованием алгоритмов искусственного интеллекта.

**Назначение проекта**
Система предназначена для автоматизации бизнес-процессов в сфере fashion-retail (интернет-магазины, стилисты, маркетплейсы). ИИ способен находить ключевую вещь на изображении, удалять фоновый шум, а также классифицировать предмет гардероба по категории, стилю, сезону и доминирующему цвету.

---

## Руководство по запуску

Для развертывания проекта не требуются навыки программирования. Вся инфраструктура запускается автоматически через приложение **Docker Desktop**.

**Шаг 1. Загрузка весов моделей**
Скачайте обученные модели с [Google Drive](https://drive.google.com/drive/folders/1Xbcpuj3874qKpg9cb09s58jXelW5-Sig?usp=drive_link).
Поместите скачанные файлы в папку `ml_service/models`, сохранив структуру каталогов из архива.

**Шаг 2. Конфигурация Telegram-бота**
Создайте файл `.env` в корне проекта рядом с `docker-compose.yml`. Впишите в него токен, полученный от BotFather:

```text
BOT_TOKEN=ваш_токен_здесь
```

**Шаг 3. Запуск системы**
Откройте терминал (командную строку) в корневой папке проекта и выполните команду:
`docker compose up --build`

Дождитесь завершения сборки контейнеров. После окончания процесса бот будет готов принимать и обрабатывать фотографии в Telegram.

---

## Визуализация результатов
Для проверки корректности работы алгоритмов система сохраняет визуальные отчеты. В папке `ml_service/inference_results` генерируются сравнительные коллажи: исходная фотография, результат сегментации (удаления фона) и аналитическая плашка с выводами нейросети.
